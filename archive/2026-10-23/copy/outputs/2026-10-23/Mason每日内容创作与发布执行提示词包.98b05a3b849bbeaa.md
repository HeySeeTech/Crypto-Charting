# Mason @Mason_NX｜每日内容创作与发布执行提示词包

## 先说结论

之前那份长提示词不适合继续作为每天的主提示词。它把研究、判断、写作、质检和运营混在一起，容易生成一份看起来完整、但不一定适合发布和复盘的长报告。

以后采用 **1 个总控提示词 + 6 个内部执行模块**。你每天只需要发送总控指令，我按顺序完成后面的模块，不需要你逐条复制。

### 七个提示词分别负责什么

| 编号 | 模块 | 谁来使用 | 作用 |
|---|---|---|---|
| 0 | 每日总控 | 你发送 | 启动当天任务，调用其余模块 |
| 1 | 开工与增量研究 | 我执行 | 检查旧内容，只找真正新增或能改判的信息 |
| 2 | Crypto Charting 数据卡 | 我执行 | 从已验证日报提炼上午可发布的数据卡 |
| 3 | 主判断与选题 | 我执行 | 决定当天只写哪一个问题 |
| 4 | 成稿 | 我执行 | 写市场判断、宏观桥接或金融认知内容 |
| 5 | 发布前质检包 | 我执行 | 去 AI 味、核数据、准备首条回复和发布说明 |
| 6 | 发布后复盘 | 你回传数据后我执行 | 比较表现，更新台账，决定下一步实验 |

你不需要每天手动调用 1—5。只有发布后，才需要把真实 X 链接和数据交给我。

## 每天发布多少条

标准日建议 **3 个内容单元**，不是每天只发一两条：

1. 上午 10:30—11:30：1 条 Crypto Charting 数据卡；
2. 中午 12:30—14:00：1 条轻内容，可以是具体回复、引用评论、财富认知、宏观桥接或当天的小观察；
3. 晚上 20:30：1 条《Mason 今日市场底稿》主帖。

三条内容的任务不同：数据卡负责回访，轻内容负责社交存在感，晚间主帖负责观点和收藏价值。每天再主动参与 5—10 条外部高质量讨论，并在自己的主帖下回复 3—5 条。回复不是“凑数量”，必须补充数据、口径、机制、反例或个人判断。

如果当天没有新的 ETF/资金披露，上午数据卡可以取消或并入中午内容；这类日期发布 2 个内容单元即可。不要为了凑数量把旧数据换一种说法重复发布。

## 你每天真正要发的启动提示词

把下面这段复制给我即可。第几天、日期和特殊要求按当天修改；不写时我根据当前日期和 14 天方案判断。

```text
开始今天的 Mason X 内容执行。

今天是【日期】，14 天方案第【X】天。
请按 Mason @Mason_NX 的每日执行 SOP 完成：
1. 读取 14 天方案、最近 7 天已用过的事实/数字/角度/结论和发布台账；
2. 检查今天是否有真正新增、发生变化或能推翻旧判断的信息；
3. 读取今天的 Crypto Charting 日报，先准备上午数据卡；
4. 按今天的栏目任务选择一个主问题，不要把多个角度拼成长报告；
5. 先形成个人判断，再写一条可直接发布的 X 文案；
6. 做事实、来源、中文逻辑、去 AI 味和 X 发布适配检查；
7. 输出数据卡、主帖、首条回复、来源和发布前清单；
8. 发布后等我提供 URL 和真实数据，再做复盘。

今天的额外要求：【可留空，例如：更偏 BTC、不要配图、希望测试短帖】
``` 

如果当天启动高频突破模式，在额外要求中写：

```text
今天启用高频突破模式，目标是 8 条独立内容和 15—25 条高质量互动。请把同一份研究拆成不同角度，不要重复数字或句子；只有数据卡和晚间主判断需要完整研究，其余内容允许是短观察、认知、引用和讨论回应。
```

## 模块 1：开工与增量研究

这是总控提示词内部调用的研究指令：

```text
先不要写文案。读取 Mason 最近的发布台账、研究笔记、已用数字和最近 7 天内容。

对今天候选信息逐条标记：
- 新事实；
- 旧事实的新数据；
- 旧判断的支持证据；
- 旧判断被削弱或推翻；
- 只是重复背景。

只保留能改变今天判断的内容。每个关键数字注明来源、采集时间、数据日期、单位、比较窗口和是否完整披露。
最后只给出 1—3 个候选问题，并说明每个问题最支持和最反对的证据。没有足够新增量时，走 no-change 路径。
```

## 模块 2：Crypto Charting 数据卡

```text
读取今天已经通过校验的 Crypto Charting JSON 和 Excel，不从截图手工抄数。

生成一张适合上午发布的数据卡说明，默认主题为 BTC/ETH ETF 或资金流。必须分开写：
- 行情采集时间；
- ETF 美东披露日期；
- 原生币持仓；
- 美元净流量；
- AUM；
- 价格变化。

数据卡只保留：当前 headline、一个可比窗口、最大增持或减持、覆盖范围、缺失项和 2—4 个直接来源。
如果没有新的 ETF 交易日，明确写“沿用最近披露日”，不把旧数据伪装成今日更新。
输出：
1. 图片上应出现的文字层级；
2. X 配文 1—2 句；
3. 适合放在评论区的来源和口径补充。
```

## 模块 3：主判断与选题

```text
基于增量研究和数据卡，选择今天唯一的主问题。

判断必须回答：发生了什么？我为什么这样判断？哪个具体数据最支持它？什么情况会让我改判？

从以下栏目中选一个，不要平均分配：
- 单一资产市场判断；
- BTC/ETH 或多资产共同问题；
- 宏观/美股到加密资产的传导；
- 财富认知；
- 读书/思想框架解释市场。

输出：
- 主问题；
- 一句话个人判断；
- 决定性数据；
- 反方证据；
- 改判条件；
- 建议格式：发现帖、证据帖、短串或认知帖。
```

## 模块 4：成稿

市场判断、宏观桥接或认知帖都从同一个判断出发，但长度由读者要完成的任务决定：

```text
根据已经确定的主判断写成稿。

先写一条可以直接发布的版本，再写来源和一句最大不确定性。不要先写报告再从报告里截句子。

要求：
- 开头直接写动作、变化或反常点；
- 只保留一个核心判断和一个决定性数据；
- 句子按中文逻辑写，短句和长句自然交替；
- 不直译英文财经摘要，不用整齐的三点列表；
- 不使用空洞的“值得注意的是”“这意味着什么”“归根结底”等套话；
- 不编造个人持仓、交易经历、争议或读者观点；
- 提问必须围绕具体数据或判断分歧；没有必要时自然停在判断上。

长度选择：
- 一个观察：2—4 行；
- 一个反常点需要证据：4—7 行；
- 多步机制：首帖 + 3—4 条回复；
- 金融认知：2—5 行，并给一个可复用的判断方法。
```

## 模块 5：发布前质检包

```text
对成稿做发布前审稿，不重写成另一篇文章。

逐项检查：
1. 首句是否让陌生读者立刻知道发生了什么；
2. 主帖是否只有一个主判断；
3. 每个数字是否有来源、日期、单位和比较窗口；
4. 是否把 ETF 流量写成全部现货需求，或把相关性写成因果；
5. 是否出现中文翻译腔、模板化对照句、抽象名词堆叠或 AI 金句；
6. 是否重复最近 7 天的事实、角度或结论；
7. 是否符合当天格式和预定发布时间；
8. 是否需要配图，配图是否真的帮助理解；
9. 回复区是否应补充口径、来源、反例或改判条件；
10. 是否存在发布前必须人工确认的事实。

输出：
- 最终发布版；
- 首条回复；
- 2—4 个来源；
- 发布前必须确认的一项内容；
- 建议的图片或“不需要图片”的结论。
```

## 模块 6：发布后复盘

发布后，把下面内容发给我：

```text
这条已经发布，请复盘：
URL：【链接】
发布时间（上海）：【时间】
首小时：曝光【】、回复【】、转发【】、点赞【】、收藏【】、主页访问【】、新增关注【】
24 小时：曝光【】、回复【】、转发【】、点赞【】、收藏【】、主页访问【】、新增关注【】
非粉丝曝光：【】
我在评论区补充了：【没有/内容】
读者出现的具体问题：【没有/问题】
```

我会把结果写入发布台账，并回答：

- 这条内容完成度如何；
- 分发信号和关系信号分别怎样；
- 哪个环节可能影响结果；
- 下一条只调整哪个主要变量；
- 是否需要补一条回复、做后续研究或停止这个角度。

没有真实 URL 和平台数据时，只能做文案审查，不能声称完成了运营复盘。

## 每天的完整执行顺序

### 上午：数据回访层（标准日第 1 条）

1. 运行 Crypto Charting 日报；
2. 校验 JSON 和 Excel；
3. 生成一张 BTC/ETH 数据卡；
4. 发布数据卡；
5. 记录 URL 和首小时数据。

### 中午：社交存在层（标准日第 2 条）

1. 选择一个值得参与的讨论或当天的小问题；
2. 写出一个具体补充，不写完整新闻摘要；
3. 如果没有合适的外部讨论，发布一条短的财富认知或市场观察；
4. 记录它是独立帖、引用帖还是回复。

### 晚上：观点层（标准日第 3 条）

1. 启动总控提示词；
2. 做增量研究；
3. 选一个主判断；
4. 写成稿；
5. 完成质检；
6. 发布《Mason 今日市场底稿》；
7. 30—60 分钟内回复 3—5 条真实讨论。

### 次日：复盘层

1. 补录上一条的 24 小时数据；
2. 写一句表现解释；
3. 只决定下一条要改的一个主要变量；
4. 不因为单条低曝光改变全部策略。

## 原提示词怎么处理

原来的长提示词不用删除。它保留为“研究约束和写作底线”，不再作为每日启动提示词。每天只发总控提示词；如果当天只想写某一类内容，可以在“额外要求”里写：

- `今天只做 BTC 判断帖`；
- `今天只做财富认知，不写价格预测`；
- `今天根据日报做数据卡和晚间判断`；
- `今天测试 2—4 行发现帖`；
- `今天测试首帖加 3 条回复的短串`。

## 两周内的执行边界

- 我负责研究、筛选、写作、质检、发布素材和复盘建议；
- 你负责确认最终文案并发布到 X，再提供真实 URL 和数据；
- 没有你的明确授权，不自动向外部平台发布；
- 14 天内不同时改变发布时间、主题比例、长度和互动方式；
- 每 3—4 天才根据滚动数据做一次小调整。
